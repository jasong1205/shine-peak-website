#### Google Ads Setup Guide

- Go to ads.google.com
- Create account with company email
- Set billing (credit card)

**Step 2: Campaign Settings**
```
Campaign Type: Search
Goal: Sales / Leads
Campaign Name: "Shine Peak - Eco Tableware"
Network: Search Network only (untick Display)
Locations: Target countries (USA, UK, Germany, Australia, etc.)
Languages: English
Bid Strategy: Maximize Clicks (start) → Target CPA (later)
Budget: $30-50/day (start) → Scale up if profitable
```

**Step 3: Keyword Research**
- Use Google Keyword Planner
- Add 10-20 keywords per ad group
- Match types: Broad Match Modifier (+keyword), Exact Match ([keyword])

**Step 4: Ad Copy (Example)**

- ✅ Fast loading (<3 seconds)
- ✅ Mobile-responsive
- ✅ Clear CTA (Get Quote button)
